用户登录

使用学号 + 密码登录，成功返回 JWT Token 与用户基础信息。连续失败 5 次锁定 15 分钟；同一 IP 每分钟最多 20 次登录请求。

请求体 · LoginRequest
字段类型必填说明
usernameString必填学号 / 用户名
passwordString必填密码
返回 data · LoginResponse
字段类型必填说明
idLong选填用户 ID
usernameString选填用户名 / 学号
tokenString选填JWT Token（后续请求头携带）
roleInteger选填角色：0-学生 1-管理员
isFirstLoginBoolean选填是否首次登录
needChangePasswordBoolean选填是否需要修改密码
